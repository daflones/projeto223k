# Eletrify — Guia de todas as imagens

O projeto inclui as imagens finais da identidade, site, vitrine, produção e distribuição, em public/assets. Os links abaixo apontam para os ativos. Rascunhos com falhas não são usados na plataforma.

As imagens de veículos são ilustrações conceituais geradas por IA; não são fotografias de uma fábrica ou estoque real nem desenhos técnicos de engenharia.

## Identidade visual

Paleta: `#0B1220`, `#00D6A0`, `#38BDF8`, `#F5F7FA`, `#64748B`. Tipografias sugeridas: Manrope e Inter.

## Como usar

- Use a logo branca sobre fundos escuros e a logo azul sobre fundos claros.
- Preserve o formato PNG para manter a transparência.
- As imagens de produção ilustram montagem e componentes; as de distribuição representam lotes de produtos prontos.
- O hero permite sobrepor título e botões à esquerda.
- Evite ampliar os PNGs além da resolução original para preservar a nitidez.
- Os arquivos em `06-rascunhos` são versões anteriores com defeitos conhecidos, incluídos apenas para histórico.
